# Bundled fonts (SIL OFL 1.1)

Noto Sans / Noto Serif (Latin) and Noto Sans SC / Noto Serif SC (Chinese), from
github.com/google/fonts (ofl/). Variable weight, subset to woff2 with fonttools:
Latin = U+0000-024F + punctuation/arrows; Chinese = GB2312 (7545 characters).
Characters outside the subset fall back to the system font.
