# Academic project

This folder is one NPi Academic research project. Work only inside it.

## Layout

| Folder | Holds | You may |
|---|---|---|
| `papers/` | Original papers (PDF and the like), one file per paper | read only, never edit, rename or delete |
| `notes/` | Reading notes, one Markdown file per paper or topic | create, edit |
| `digests/` | Structured summaries: section digests and whole-paper digests | create, edit |
| `artifacts/` | Comparison tables, argument maps, other derived results | create, edit |
| `data/raw/` | Source data exactly as received | read only |
| `data/processed/` | Cleaned or computed data, with the script or steps that made it | create, edit |
| `drafts/` | The user's own writing | edit only when asked |
| `write/` | The paper: a Git repository with Markdown drafts, compiled LaTeX and the linked result | edit `markdown/` and `template.tex` when asked; `latex/` and `output/` are generated |
| `.npi-academic/` | Project metadata managed by the app | do not touch |

## How to work

- Answer from the papers and notes in this project. Say plainly when they do not contain the answer.
- Every factual claim taken from a paper carries a source: paper file name, page, and a short exact quote.
- File naming: `papers/<year>-<firstauthor>-<short-title>.pdf`; notes and digests reuse the same stem.
- Follow `RULES.md`. Use the skills under `.omp/skills/` for intake, digests and data processing.
- Reply in the user's language.
