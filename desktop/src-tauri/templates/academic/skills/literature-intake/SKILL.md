# Literature intake

Use when the user adds a paper to `papers/` or asks to register one.

1. Read the paper; do not move or rename the original unless the user asks. If the file name does not follow `<year>-<firstauthor>-<short-title>`, propose the name and wait.
2. Create `notes/<stem>.md` with: title, authors, year, venue, DOI (only if printed in the paper), and a one-line statement of what the paper is about.
3. Add the section outline with page numbers.
4. List what could not be read (scanned pages, tables or formulas that did not extract) so nothing is silently skipped.
5. Do not summarize yet; that is the `paper-digest` skill.
